# 활천중학교 제규정 검색 시스템

GitHub Pages용 정적 웹앱입니다.

## 매년 업데이트하는 방법
1. 새 규정집 PDF를 이 저장소에 업로드합니다.
2. `config.js`에서 `year`, `pdfFile`, `pageOffset`, `rules`만 수정합니다.
3. `rules`의 `page`에는 PDF 뷰어 번호가 아니라 규정집에 인쇄된 시작 쪽수를 입력합니다.
4. `main` 브랜치에 Commit하면 GitHub Pages가 다시 배포됩니다.

## 새 규정 추가 예시
```js
{ name: "새로 생긴 규정", page: 120 },
```
위 한 줄을 실제 목차 순서에 맞는 위치에 추가하면 번호와 끝 쪽수는 웹앱이 자동 계산합니다.

## pageOffset
현재 PDF는 표지/차례 2쪽 뒤부터 규정집 1쪽이 시작하므로 `pageOffset: 2`입니다.
내년 PDF 구성이 바뀌면 이 값만 맞추면 됩니다.

## 특정 규정 바로 공유
웹앱 주소 뒤에 `?rule=12`처럼 붙이면 12번 규정이 바로 열립니다.
상단의 `현재 규정 링크` 버튼을 누르면 현재 규정 주소가 복사됩니다.

## 학교 홈페이지 원문 버튼
`config.js`의 `officialPage`에 학교 홈페이지의 공식 게시글 URL을 넣으면 버튼이 자동으로 표시됩니다.
